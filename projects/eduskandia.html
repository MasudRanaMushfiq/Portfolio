Eduskandia is a European education consultancy that helps international students study in the Nordics. I built the platform end to end: a Laravel RESTful API that holds programs, institutions, students, applications and articles, and a React frontend that turns it into a guided journey from first shortlist to final visa decision. It lists verified, English-taught programs from partner universities across seven countries, including tuition-free options.

Problem

Students applying to Nordic universities from abroad face scattered program information, unclear tuition and fees, confusing document requirements, and no single place to see where their application stands. The consultancy needed one platform that presents verified programs transparently and guides each student from first shortlist to visa decision.

Solution

Built a Laravel RESTful API that holds programs, partner institutions, student accounts, applications and blog content, and a React frontend (Next.js, Tailwind CSS) that consumes it. Students search and filter the catalog, see every cost before applying, sign in to apply, and follow their application through clear stages on a dashboard, while the team publishes new programs and articles without touching code.

Challenges & Engineering Deep Dive

Making a Multi-Country Catalog Easy to Search

Programs span several countries, universities and study levels, and students usually arrive knowing only a subject or a country they like.


How I solved it: the API exposes one search that matches either a program name or a country, plus country and level filters. Each program gets its own page with the details students compare first: university, city, level, duration and intakes.

Being Upfront About Every Cost

Students often discover application fees and service charges late, which damages trust in a consultancy.


How I solved it: each program stores its tuition, application fee, file opening fee and service charge alongside its requirements, and the program page shows all of them before the student signs in to apply.

Showing Students Where Their Application Stands

Applying abroad involves many steps, and students lose track of what is done and what is still missing.


How I solved it: applications are modelled in the backend as clear stages (profile, documents, submission). The dashboard reads them from the API and shows a progress indicator, so students always know the next step.

Content the Team Can Update Without a Developer

Programs, intakes, partner universities and guidance articles change every admissions cycle.


How I solved it: all of this content lives in the Laravel backend and is served through the API, so the team can add a program or publish an article and it appears on the site immediately, with homepage statistics updating from the same data.
